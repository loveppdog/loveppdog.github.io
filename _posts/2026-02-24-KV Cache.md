# KV Cache：大模型推理加速的核心机制

## 一、KV Cache 的基本概念

### 1.1 什么是 KV Cache？

**KV Cache（Key-Value Cache）** 是 Transformer 模型在自回归生成过程中，用于缓存 **注意力机制中间计算结果** 的一种优化技术。

```python
# 没有 KV Cache 的原始计算
def generate_without_cache(model, input_ids, max_length):
    generated = []
    current_ids = input_ids
    
    for _ in range(max_length):
        # 每次都要重新计算整个序列的注意力
        outputs = model(current_ids)  # 重复计算相同的键值
        next_token = sample(outputs.logits[:, -1, :])
        current_ids = torch.cat([current_ids, next_token], dim=1)
        generated.append(next_token)
    
    return generated

# 使用 KV Cache 的计算
def generate_with_cache(model, input_ids, max_length):
    generated = []
    current_ids = input_ids
    
    # 初始化 KV Cache
    past_key_values = None
    
    for step in range(max_length):
        # 仅传入最后一个token，重用之前的KV Cache
        outputs = model(
            current_ids[:, -1:],  # 只输入最新token
            past_key_values=past_key_values  # 重用缓存
        )
        
        # 更新 KV Cache
        past_key_values = outputs.past_key_values
        
        next_token = sample(outputs.logits[:, -1, :])
        current_ids = torch.cat([current_ids, next_token], dim=1)
        generated.append(next_token)
    
    return generated
```

### 1.2 为什么需要 KV Cache？

**根本问题**：Transformer 注意力计算的时间复杂度为 O(n²)，其中 n 是序列长度。

```
序列长度 vs 计算量：
长度=1:   1次注意力计算
长度=2:   4次（增长4倍）
长度=10:  100次
长度=100: 10000次
长度=1000: 1000000次
```

**KV Cache 的核心洞察**：
```
在自回归生成中，当生成第 t 个 token 时：
1. 前 t-1 个 token 的键（K）和值（V）已经计算过
2. 这些计算结果在第 t 步仍然有效
3. 只需计算第 t 个 token 对应的 K 和 V
```

## 二、Transformer 注意力机制回顾

### 2.1 标准注意力计算

```python
def attention(q, k, v, mask=None):
    """
    q: query [batch, heads, seq_len, dim]
    k: key   [batch, heads, seq_len, dim]
    v: value [batch, heads, seq_len, dim]
    """
    # 计算注意力分数
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(dim)
    
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    
    # softmax 归一化
    attn_weights = torch.softmax(scores, dim=-1)
    
    # 加权求和
    output = torch.matmul(attn_weights, v)
    
    return output, attn_weights
```

### 2.2 自回归生成的注意力模式

在生成模式下，使用 **因果掩码（Causal Mask）**：

```python
def causal_mask(seq_len):
    """
    创建下三角矩阵，防止看到未来信息
    [[1, 0, 0, 0],
     [1, 1, 0, 0],
     [1, 1, 1, 0],
     [1, 1, 1, 1]]
    """
    mask = torch.tril(torch.ones(seq_len, seq_len))
    return mask
```

这意味着：
- 第 t 个 token 只能看到前 t 个 token
- 当计算第 t+1 个 token 时，前 t 个 token 的 K, V 可以复用

## 三、KV Cache 的详细实现

### 3.1 数据结构设计

```python
class KVCache:
    def __init__(self, num_layers, num_heads, head_dim, dtype=torch.float16):
        """
        KV Cache 的数据结构
        
        对于每个 Transformer 层：
        - keys:   [batch, heads, seq_len, head_dim]
        - values: [batch, heads, seq_len, head_dim]
        """
        self.num_layers = num_layers
        self.num_heads = num_heads
        self.head_dim = head_dim
        
        # 存储每一层的 K 和 V
        self.keys = [None] * num_layers    # 列表存储每一层的 K tensor
        self.values = [None] * num_layers   # 列表存储每一层的 V tensor
        
        # 当前缓存的序列长度
        self.cache_length = 0
        
    def update(self, layer_idx, new_keys, new_values):
        """
        更新指定层的 KV Cache
        
        new_keys:   [batch, heads, new_seq_len, head_dim]
        new_values: [batch, heads, new_seq_len, head_dim]
        """
        if self.keys[layer_idx] is None:
            # 第一次初始化
            self.keys[layer_idx] = new_keys
            self.values[layer_idx] = new_values
        else:
            # 拼接新的 K, V 到缓存末尾
            self.keys[layer_idx] = torch.cat(
                [self.keys[layer_idx], new_keys], dim=2
            )
            self.values[layer_idx] = torch.cat(
                [self.values[layer_idx], new_values], dim=2
            )
        
        self.cache_length = self.keys[layer_idx].shape[2]
    
    def get(self, layer_idx):
        """获取指定层的 K, V 缓存"""
        return self.keys[layer_idx], self.values[layer_idx]
    
    def clear(self):
        """清空缓存"""
        self.keys = [None] * self.num_layers
        self.values = [None] * self.num_layers
        self.cache_length = 0
```

### 3.2 集成到 Transformer 层

```python
class TransformerLayerWithKVCache(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.attention = MultiHeadAttention(config)
        self.mlp = MLP(config)
        self.norm1 = nn.LayerNorm(config.hidden_size)
        self.norm2 = nn.LayerNorm(config.hidden_size)
        
        # 投影层：用于生成 K, Q, V
        self.q_proj = nn.Linear(config.hidden_size, config.hidden_size)
        self.k_proj = nn.Linear(config.hidden_size, config.hidden_size)
        self.v_proj = nn.Linear(config.hidden_size, config.hidden_size)
        self.out_proj = nn.Linear(config.hidden_size, config.hidden_size)
        
        self.num_heads = config.num_heads
        self.head_dim = config.hidden_size // config.num_heads
        
    def forward(self, hidden_states, attention_mask=None, past_key_value=None, use_cache=False):
        """
        hidden_states: [batch, seq_len, hidden_size]
        past_key_value: 上一轮的 KV Cache
        use_cache: 是否使用/更新 KV Cache
        """
        # LayerNorm
        residual = hidden_states
        hidden_states = self.norm1(hidden_states)
        
        # 计算 Q, K, V
        batch_size, seq_len, _ = hidden_states.shape
        q = self.q_proj(hidden_states)
        k = self.k_proj(hidden_states)
        v = self.v_proj(hidden_states)
        
        # 重塑为多头格式
        q = q.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        k = k.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(batch_size, seq_len, self.num_heads, self.head_dim).transpose(1, 2)
        
        if past_key_value is not None:
            # 有历史缓存：拼接新的 K, V
            past_key, past_value = past_key_value
            k = torch.cat([past_key, k], dim=2)
            v = torch.cat([past_value, v], dim=2)
        
        # 保存当前层的 K, V 用于下一轮
        present_key_value = (k, v) if use_cache else None
        
        # 计算注意力
        attn_output = self.scaled_dot_product_attention(q, k, v, attention_mask)
        
        # 重塑回原始形状
        attn_output = attn_output.transpose(1, 2).contiguous()
        attn_output = attn_output.view(batch_size, seq_len, -1)
        
        # 输出投影
        attn_output = self.out_proj(attn_output)
        
        # 残差连接
        attn_output = residual + attn_output
        
        # MLP 部分
        mlp_output = self.mlp(self.norm2(attn_output))
        output = attn_output + mlp_output
        
        return output, present_key_value
    
    def scaled_dot_product_attention(self, q, k, v, mask=None):
        """
        带因果掩码的注意力计算
        """
        # 计算注意力分数
        attn_scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        
        # 应用因果掩码
        if mask is not None:
            attn_scores = attn_scores + mask
        
        # 对于自回归生成，自动创建因果掩码
        seq_len = k.shape[2]
        if seq_len > 1:
            # 创建下三角因果掩码
            causal_mask = torch.tril(
                torch.ones(seq_len, seq_len, device=q.device)
            ).view(1, 1, seq_len, seq_len)
            # 将上三角部分设为负无穷
            attn_scores = attn_scores.masked_fill(causal_mask == 0, float('-inf'))
        
        # Softmax
        attn_weights = torch.softmax(attn_scores, dim=-1)
        
        # 加权求和
        attn_output = torch.matmul(attn_weights, v)
        
        return attn_output
```

### 3.3 完整的生成流程

```python
class TransformerModelWithKVCache(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.embedding = nn.Embedding(config.vocab_size, config.hidden_size)
        self.layers = nn.ModuleList([
            TransformerLayerWithKVCache(config) for _ in range(config.num_layers)
        ])
        self.ln_f = nn.LayerNorm(config.hidden_size)
        self.lm_head = nn.Linear(config.hidden_size, config.vocab_size, bias=False)
        
        self.config = config
        
    def forward(self, input_ids, attention_mask=None, past_key_values=None, use_cache=False):
        """
        input_ids: [batch, seq_len]
        past_key_values: 多层 KV Cache 的元组
        """
        batch_size, seq_len = input_ids.shape
        
        # 获取输入嵌入
        hidden_states = self.embedding(input_ids)
        
        # 如果使用 KV Cache，hidden_states 只包含最新token
        if past_key_values is not None:
            # 隐藏状态只包含新token
            # 但 K, V 缓存中包含了所有历史token
            pass
        
        # 准备 attention mask
        if attention_mask is None:
            attention_mask = torch.ones(batch_size, seq_len, device=input_ids.device)
        
        # 扩展 mask 用于多头注意力
        attention_mask = attention_mask[:, None, None, :]
        
        # 如果使用 KV Cache，需要扩展 mask 以匹配缓存长度
        if past_key_values is not None:
            cache_len = past_key_values[0][0].shape[2]  # 获取缓存长度
            seq_len_with_cache = cache_len + seq_len
            
            # 创建扩展的 attention mask
            extended_attention_mask = torch.cat([
                torch.ones(batch_size, 1, 1, cache_len, device=input_ids.device),
                attention_mask
            ], dim=-1)
        else:
            extended_attention_mask = attention_mask
            seq_len_with_cache = seq_len
        
        # 处理每一层
        present_key_values = () if use_cache else None
        all_hidden_states = ()
        
        for layer_idx, layer in enumerate(self.layers):
            # 获取当前层的历史缓存
            layer_past = None
            if past_key_values is not None:
                layer_past = past_key_values[layer_idx]
            
            # 前向传播
            hidden_states, layer_present = layer(
                hidden_states,
                attention_mask=extended_attention_mask,
                past_key_value=layer_past,
                use_cache=use_cache
            )
            
            if use_cache:
                present_key_values = present_key_values + (layer_present,)
            
            all_hidden_states = all_hidden_states + (hidden_states,)
        
        # 最终层归一化
        hidden_states = self.ln_f(hidden_states)
        
        # 语言模型头
        logits = self.lm_head(hidden_states)
        
        return {
            "logits": logits,
            "past_key_values": present_key_values,
            "hidden_states": all_hidden_states
        }
    
    def generate(self, input_ids, max_length=100, temperature=1.0):
        """
        使用 KV Cache 的自回归生成
        """
        batch_size = input_ids.shape[0]
        device = input_ids.device
        
        # 初始化 KV Cache
        past_key_values = None
        
        # 存储生成的 token
        generated_ids = input_ids.clone()
        
        for step in range(max_length):
            # 准备当前输入（如果是第一步，使用全部输入；否则只使用最新token）
            if step == 0:
                current_input = input_ids
            else:
                current_input = generated_ids[:, -1:]
            
            # 前向传播，使用/更新 KV Cache
            outputs = self(
                input_ids=current_input,
                past_key_values=past_key_values,
                use_cache=True
            )
            
            # 更新 KV Cache
            past_key_values = outputs["past_key_values"]
            
            # 获取下一个 token 的 logits
            next_token_logits = outputs["logits"][:, -1, :] / temperature
            
            # 采样（这里使用贪婪采样）
            next_token = torch.argmax(next_token_logits, dim=-1, keepdim=True)
            
            # 添加到生成序列
            generated_ids = torch.cat([generated_ids, next_token], dim=1)
            
            # 检查是否生成了结束符
            if torch.all(next_token == self.config.eos_token_id):
                break
        
        return generated_ids
```

## 四、KV Cache 的内存分析

### 4.1 内存占用计算

```python
def calculate_kv_cache_memory(model_config, batch_size, seq_length, dtype_bytes=2):
    """
    计算 KV Cache 的内存占用
    
    参数：
    - model_config: 模型配置（层数、头数、隐藏维度）
    - batch_size: 批大小
    - seq_length: 序列长度
    - dtype_bytes: 数据类型字节数（fp16=2, fp32=4, int8=1）
    
    返回：内存占用（字节）
    """
    num_layers = model_config.num_layers
    num_heads = model_config.num_attention_heads
    hidden_size = model_config.hidden_size
    
    # 每个头的维度
    head_dim = hidden_size // num_heads
    
    # 每层 K 和 V 的存储
    # 形状：[batch, heads, seq_len, head_dim]
    kv_per_layer = 2  # K 和 V
    kv_elements_per_layer = batch_size * num_heads * seq_length * head_dim
    
    # 总元素数
    total_elements = num_layers * kv_per_layer * kv_elements_per_layer
    
    # 总内存（字节）
    total_memory_bytes = total_elements * dtype_bytes
    
    return total_memory_bytes
```

```python
def compare_memory_usage(model_config, batch_size=1, seq_length=1024):
    """
    比较 KV Cache 和模型权重的内存占用
    """
    # 1. 计算 KV Cache 内存
    kv_cache_memory = calculate_kv_cache_memory(
        model_config, batch_size, seq_length
    )
    
    # 2. 计算模型权重内存（粗略估计）
    # LLaMA-7B 实际参数约 6.74B，fp16 约 13.48 GB
    # 这里简化为公式估算
    hidden_size = model_config.hidden_size
    num_layers = model_config.num_layers
    vocab_size = 32000  # 典型词汇表大小
    
    # 主要权重组件：
    # - 注意力 QKV 投影: 3 * hidden_size * hidden_size
    # - 注意力输出投影: hidden_size * hidden_size
    # - MLP 两层: 4 * hidden_size * hidden_size * 2
    # - 层归一化: 可忽略
    # - 词嵌入: vocab_size * hidden_size
    
    attention_params = 4 * hidden_size * hidden_size  # QKV + 输出
    mlp_params = 8 * hidden_size * hidden_size  # 两层 MLP
    embedding_params = vocab_size * hidden_size
    
    total_params = num_layers * (attention_params + mlp_params) + embedding_params
    
    # fp16 内存（2字节/参数）
    weight_memory = total_params * 2
    
    # 3. 打印比较
    print("=== 内存占用比较 ===")
    print(f"模型参数数量: {total_params/1e9:.2f}B")
    print(f"权重内存 (fp16): {weight_memory/(1024**3):.2f} GB")
    print(f"KV Cache 内存 (batch={batch_size}, seq={seq_length}): {kv_cache_memory/(1024**3):.2f} GB")
    print(f"KV Cache / 权重: {kv_cache_memory/weight_memory:.2%}")
    
    return kv_cache_memory, weight_memory
```

## 五、KV Cache 的优化策略

### 5.1 内存优化技术

#### 5.1.1 分页 KV Cache（Paged Attention）

```python
class PagedKVCache:
    """
    分页 KV Cache - 类似虚拟内存分页
    灵感来自 vLLM 的 PagedAttention
    """
    def __init__(self, block_size=16, num_blocks=1024, head_dim=128):
        """
        block_size: 每个块存储的token数
        num_blocks: 块总数
        head_dim: 每个头的维度
        """
        self.block_size = block_size
        self.num_blocks = num_blocks
        self.head_dim = head_dim
        
        # 物理内存：预分配的固定大小块
        self.key_blocks = torch.zeros(
            num_blocks, block_size, head_dim, dtype=torch.float16
        )
        self.value_blocks = torch.zeros(
            num_blocks, block_size, head_dim, dtype=torch.float16
        )
        
        # 块分配表：记录哪些块被使用
        self.block_table = torch.zeros(num_blocks, dtype=torch.bool)
        
        # 逻辑到物理的映射
        self.logical_to_physical = {}  # sequence_id -> [block_ids]
        
    def allocate_for_sequence(self, sequence_id, required_tokens):
        """
        为序列分配物理块
        """
        # 计算需要的块数
        num_blocks_needed = (required_tokens + self.block_size - 1) // self.block_size
        
        # 查找空闲块
        free_blocks = torch.where(~self.block_table)[0]
        if len(free_blocks) < num_blocks_needed:
            raise MemoryError("Not enough free blocks")
        
        # 分配块
        allocated_blocks = free_blocks[:num_blocks_needed].tolist()
        for block_id in allocated_blocks:
            self.block_table[block_id] = True
        
        # 建立映射
        self.logical_to_physical[sequence_id] = allocated_blocks
        
        return allocated_blocks
    
    def write_to_cache(self, sequence_id, new_keys, new_values, start_token_idx):
        """
        将新的 K, V 写入缓存
        """
        if sequence_id not in self.logical_to_physical:
            raise ValueError(f"Sequence {sequence_id} not allocated")
        
        block_ids = self.logical_to_physical[sequence_id]
        
        # 计算写入位置
        block_idx = start_token_idx // self.block_size
        offset_in_block = start_token_idx % self.block_size
        
        # 写入数据
        write_length = new_keys.shape[0]
        
        for i in range(write_length):
            current_block = block_ids[block_idx]
            pos_in_block = offset_in_block + i
            
            # 如果当前块写满，移到下一块
            if pos_in_block >= self.block_size:
                block_idx += 1
                pos_in_block = 0
                current_block = block_ids[block_idx]
            
            # 写入数据
            self.key_blocks[current_block, pos_in_block] = new_keys[i]
            self.value_blocks[current_block, pos_in_block] = new_values[i]
    
    def read_from_cache(self, sequence_id, token_indices):
        """
        从缓存读取指定位置的 K, V
        """
        block_ids = self.logical_to_physical[sequence_id]
        
        keys = []
        values = []
        
        for token_idx in token_indices:
            block_idx = token_idx // self.block_size
            offset_in_block = token_idx % self.block_size
            
            block_id = block_ids[block_idx]
            
            keys.append(self.key_blocks[block_id, offset_in_block])
            values.append(self.value_blocks[block_id, offset_in_block])
        
        return torch.stack(keys), torch.stack(values)
    
    def free_sequence(self, sequence_id):
        """
        释放序列占用的块
        """
        if sequence_id in self.logical_to_physical:
            block_ids = self.logical_to_physical[sequence_id]
            for block_id in block_ids:
                self.block_table[block_id] = False
            del self.logical_to_physical[sequence_id]
```

#### 5.1.2 量化 KV Cache

```python
class QuantizedKVCache:
    """
    量化 KV Cache：使用低精度存储
    """
    def __init__(self, num_layers, num_heads, head_dim, quant_bits=8):
        self.num_layers = num_layers
        self.num_heads = num_heads
        self.head_dim = head_dim
        self.quant_bits = quant_bits
        
        # 量化参数
        self.quant_min = -(2 ** (quant_bits - 1))
        self.quant_max = 2 ** (quant_bits - 1) - 1
        
        # 存储量化后的数据
        self.quantized_keys = [None] * num_layers
        self.quantized_values = [None] * num_layers
        
        # 存储量化参数（scale 和 zero_point）
        self.key_scales = [None] * num_layers
        self.key_zero_points = [None] * num_layers
        self.value_scales = [None] * num_layers
        self.value_zero_points = [None] * num_layers
        
    def quantize_tensor(self, tensor):
        """
        对称量化
        """
        # 计算量化参数
        abs_max = torch.max(torch.abs(tensor))
        scale = abs_max / self.quant_max
        
        # 量化
        quantized = torch.round(tensor / scale).clamp(
            self.quant_min, self.quant_max
        ).to(torch.int8)
        
        return quantized, scale
    
    def dequantize_tensor(self, quantized, scale):
        """
        反量化
        """
        return quantized.float() * scale
    
    def update(self, layer_idx, new_keys, new_values):
        """
        更新量化缓存
        """
        # 量化新的 K, V
        quantized_keys, key_scale = self.quantize_tensor(new_keys)
        quantized_values, value_scale = self.quantize_tensor(new_values)
        
        if self.quantized_keys[layer_idx] is None:
            # 首次存储
            self.quantized_keys[layer_idx] = quantized_keys
            self.quantized_values[layer_idx] = quantized_values
            self.key_scales[layer_idx] = key_scale
            self.value_scales[layer_idx] = value_scale
        else:
            # 拼接
            self.quantized_keys[layer_idx] = torch.cat([
                self.quantized_keys[layer_idx], quantized_keys
            ], dim=2)
            self.quantized_values[layer_idx] = torch.cat([
                self.quantized_values[layer_idx], quantized_values
            ], dim=2)
            
            # 更新量化参数（使用最新块的scale）
            self.key_scales[layer_idx] = torch.cat([
                self.key_scales[layer_idx], key_scale.unsqueeze(0)
            ])
            self.value_scales[layer_idx] = torch.cat([
                self.value_scales[layer_idx], value_scale.unsqueeze(0)
            ])
    
    def get(self, layer_idx, token_indices=None):
        """
        获取并反量化指定位置的 K, V
        """
        if token_indices is None:
            # 获取全部
            keys = self.dequantize_tensor(
                self.quantized_keys[layer_idx],
                self.key_scales[layer_idx]
            )
            values = self.dequantize_tensor(
                self.quantized_values[layer_idx],
                self.value_scales[layer_idx]
            )
        else:
            # 获取指定位置
            # 这里简化处理，实际需要处理多尺度
            keys = self.dequantize_tensor(
                self.quantized_keys[layer_idx][:, :, token_indices],
                self.key_scales[layer_idx][:, :, token_indices]
            )
            values = self.dequantize_tensor(
                self.quantized_values[layer_idx][:, :, token_indices],
                self.value_scales[layer_idx][:, :, token_indices]
            )
        
        return keys, values
```

```python
class IncrementalKVCacheUpdate:
    """
    增量更新 KV Cache，避免不必要的内存复制
    """
    def __init__(self, chunk_size=64):
        """
        chunk_size: 每次更新的块大小
        """
        self.chunk_size = chunk_size
        self.cache_chunks = {}  # sequence_id -> list of chunks
    
    def update_incrementally(self, sequence_id, new_keys, new_values, layer_idx):
        """
        增量更新缓存
        """
        if sequence_id not in self.cache_chunks:
            self.cache_chunks[sequence_id] = []
        
        # 将新数据分块
        num_tokens = new_keys.shape[2]
        num_chunks = (num_tokens + self.chunk_size - 1) // self.chunk_size
        
        for i in range(num_chunks):
            start = i * self.chunk_size
            end = min((i + 1) * self.chunk_size, num_tokens)
            
            key_chunk = new_keys[:, :, start:end]
            value_chunk = new_values[:, :, start:end]
            
            # 存储块
            chunk_id = len(self.cache_chunks[sequence_id])
            self.cache_chunks[sequence_id].append({
                'keys': key_chunk,
                'values': value_chunk,
                'layer': layer_idx,
                'start_token': start,
                'end_token': end
            })
    
    def get_contiguous_cache(self, sequence_id, layer_idx, up_to_token):
        """
        获取连续的内存视图（惰性拼接）
        """
        relevant_chunks = [
            chunk for chunk in self.cache_chunks[sequence_id]
            if chunk['layer'] == layer_idx and chunk['end_token'] <= up_to_token
        ]
        
        # 按起始位置排序
        relevant_chunks.sort(key=lambda x: x['start_token'])
        
        # 检查是否需要实际拼接
        # 如果 chunk 是连续的，可以直接使用视图
        is_contiguous = True
        for i in range(1, len(relevant_chunks)):
            if relevant_chunks[i]['start_token'] != relevant_chunks[i-1]['end_token']:
                is_contiguous = False
                break
        
        if is_contiguous and len(relevant_chunks) > 0:
            # 可以使用 torch.cat 创建视图，但不立即复制数据
            keys = torch.cat([chunk['keys'] for chunk in relevant_chunks], dim=2)
            values = torch.cat([chunk['values'] for chunk in relevant_chunks], dim=2)
        else:
            # 需要实际拼接
            total_tokens = up_to_token
            keys = torch.zeros(
                relevant_chunks[0]['keys'].shape[0],
                relevant_chunks[0]['keys'].shape[1],
                total_tokens,
                dtype=relevant_chunks[0]['keys'].dtype,
                device=relevant_chunks[0]['keys'].device
            )
            values = torch.zeros_like(keys)
            
            for chunk in relevant_chunks:
                start = chunk['start_token']
                end = chunk['end_token']
                keys[:, :, start:end] = chunk['keys']
                values[:, :, start:end] = chunk['values']
        
        return keys, values
```

### 6.2 持续批处理（Continuous Batching）

```python
class ContinuousBatchingWithKVCache:
    """
    持续批处理：动态添加/移除序列
    """
    def __init__(self, model, max_batch_size=32):
        self.model = model
        self.max_batch_size = max_batch_size
        
        # 序列状态跟踪
        self.sequences = {}  # sequence_id -> 状态
        self.next_sequence_id = 0
        
        # KV Cache 管理
        self.kv_cache = {}  # sequence_id -> past_key_values
        
        # 批处理调度
        self.scheduler = Scheduler()
    
    def add_sequence(self, prompt):
        """
        添加新序列到批处理
        """
        sequence_id = self.next_sequence_id
        self.next_sequence_id += 1
        
        self.sequences[sequence_id] = {
            'input_ids': prompt,
            'status': 'active',
            'generated_tokens': [],
            'position': 0
        }
        
        # 初始化该序列的 KV Cache
        self.kv_cache[sequence_id] = None
        
        return sequence_id
    
    def remove_sequence(self, sequence_id):
        """
        移除序列（生成完成或用户取消）
        """
        if sequence_id in self.sequences:
            del self.sequences[sequence_id]
        
        if sequence_id in self.kv_cache:
            del self.kv_cache[sequence_id]
    
    def generate_batch(self):
        """
        执行一次批处理生成
        """
        # 准备当前活跃序列
        active_sequences = [
            seq_id for seq_id, info in self.sequences.items()
            if info['status'] == 'active'
        ]
        
        if not active_sequences:
            return
        
        # 构建批处理输入
        batch_inputs = []
        batch_attention_masks = []
        batch_past_key_values = []
        batch_positions = []
        
        for seq_id in active_sequences:
            seq_info = self.sequences[seq_id]
            
            # 当前输入：对于新序列是全部prompt，对于生成中的序列是最后一个token
            if seq_info['position'] == 0:
                current_input = seq_info['input_ids']
            else:
                current_input = seq_info['generated_tokens'][-1:]
            
            batch_inputs.append(current_input)
            
            # 位置信息
            batch_positions.append(seq_info['position'])
            
            # KV Cache
            batch_past_key_values.append(self.kv_cache[seq_id])
            
            # Attention mask（考虑缓存长度）
            cache_len = 0
            if self.kv_cache[seq_id] is not None:
                cache_len = self.kv_cache[seq_id][0][0].shape[2]
            
            total_len = cache_len + current_input.shape[1]
            mask = torch.ones(total_len, dtype=torch.bool)
            batch_attention_masks.append(mask)
        
        # 填充批次到统一长度
        padded_batch = self.pad_batch(batch_inputs, batch_attention_masks)
        
        # 模型前向传播
        outputs = self.model(
            input_ids=padded_batch['input_ids'],
            attention_mask=padded_batch['attention_mask'],
            past_key_values=batch_past_key_values if any(batch_past_key_values) else None,
            use_cache=True
        )
        
        # 更新每个序列
        for i, seq_id in enumerate(active_sequences):
            # 获取该序列对应的输出
            seq_output = {
                'logits': outputs['logits'][i:i+1],
                'past_key_values': tuple(
                    (k[i:i+1], v[i:i+1]) 
                    for k, v in outputs['past_key_values']
                )
            }
            
            # 更新该序列的 KV Cache
            self.kv_cache[seq_id] = seq_output['past_key_values']
            
            # 采样下一个 token
            next_token = sample(seq_output['logits'][:, -1, :])
            
            # 更新序列状态
            self.sequences[seq_id]['generated_tokens'].append(next_token)
            self.sequences[seq_id]['position'] += 1
            
            # 检查是否结束
            if next_token.item() == self.model.config.eos_token_id:
                self.sequences[seq_id]['status'] = 'completed'
    
    def pad_batch(self, inputs, masks):
        """
        将不同长度的输入填充到相同长度
        """
        max_len = max(inp.shape[1] for inp in inputs)
        
        padded_inputs = []
        padded_masks = []
        
        for inp, mask in zip(inputs, masks):
            # 填充输入
            pad_len = max_len - inp.shape[1]
            if pad_len > 0:
                padded = torch.nn.functional.pad(
                    inp, 
                    (0, pad_len), 
                    value=self.model.config.pad_token_id
                )
            else:
                padded = inp
            
            padded_inputs.append(padded)
            
            # 填充 attention mask
            mask_pad_len = max_len - mask.shape[0]
            if mask_pad_len > 0:
                padded_mask = torch.nn.functional.pad(
                    mask, 
                    (0, mask_pad_len), 
                    value=False
                )
            else:
                padded_mask = mask
            
            padded_masks.append(padded_mask)
        
        return {
            'input_ids': torch.cat(padded_inputs, dim=0),
            'attention_mask': torch.stack(padded_masks, dim=0)
        }
```

```python
            past_key_values=past_key_values,
            use_cache=True
        )
    
    # 更新KV Cache
    past_key_values = outputs.past_key_values
    
    # 采样下一个token
    next_token = torch.argmax(outputs.logits[:, -1, :], dim=-1)
    
    # 添加到生成序列
    generated = torch.cat([generated, next_token.unsqueeze(-1)], dim=-1)

# 解码结果
result = tokenizer.decode(generated[0], skip_special_tokens=True)
print(result)
```

   ```python
   class SelectiveKVCache:
       def should_cache(self, attention_scores):

           importance = torch.max(attention_scores, dim=-1)[0]
   ```

   ```python
   class HierarchicalKVCache:

           # L2: CPU内存（较慢，容量大）
   ```

   ```python
   class LearnedCachePolicy:
   ```

## 十、总结

**KV Cache 是大模型推理优化的基石技术**，它通过：

### **核心价值**：
1. **显著降低计算量**：从 O(n²) 降至 O(n)
2. **大幅提升吞吐量**：典型加速 2-10 倍
3. **支持长序列生成**：使 100K+ token 序列成为可能

### **关键挑战**：
1. **内存占用**：需平衡速度和内存
2. **管理复杂性**：动态批处理、分页、量化
3. **硬件限制**：内存带宽瓶颈


**研究方向**：
1. 智能缓存替换策略
2. 异构内存架构优化
3. 与新型注意力机制结合（如 MQA、GQA）

KV Cache 技术仍在快速发展，掌握它将使你在高效推理系统设计中保持领先优势。
