### 一、先搞懂核心概念
RVV 是 RISC-V 架构的向量指令集扩展，专门用于加速矩阵运算、数据并行处理（比如AI算子、信号处理）。编译 RVV 算子的核心目标是：
1. 让编译器识别 RVV 指令集；
2. 将算子代码（C/C++/汇编）编译为支持 RVV 的二进制指令；
3. 适配不同的 RVV 版本（如 0.7.1/1.0）和向量长度（VLEN，如 128/256/512）。

### 二、编译前的准备工作
#### 1. 必备工具链
RVV 算子编译依赖**支持 RISC-V RVV 的编译器**，主流选择：
- **GCC**：推荐版本 ≥ 12（对 RVV 1.0 支持完善）；
- **Clang/LLVM**：推荐版本 ≥ 15；
- **RISC-V 交叉编译工具链**：需编译时开启 RVV 支持（如 `riscv64-linux-gnu-gcc`）。

#### 2. 验证工具链是否支持 RVV
执行以下命令，查看编译器是否识别 RVV 相关参数：
```bash
# 以 riscv64-linux-gnu-gcc 为例
riscv64-linux-gnu-gcc -march=rv64gcv -Q --help=target | grep v
```
若输出包含 `rv64gcv`（rv64 + 通用指令 + RVV），说明工具链支持 RVV。

### 三、RVV 算子编译核心步骤（以 GCC 为例）
#### 步骤1：编写 RVV 算子代码
RVV 算子代码有两种写法：
- **方式1：C/C++ 内置函数（推荐，无需手写汇编）**  
  GCC 提供 RVV 内置函数（如 `vadd.vv` 向量加法、`vmul.vv` 向量乘法），示例（向量加法算子）：
  ```c
  #include <riscv_vector.h> // 必须包含 RVV 头文件

  // RVV 向量加法算子：a + b → c（len 为向量元素个数，elem_size 为元素字节数）
  void rvv_vector_add(void *c, const void *a, const void *b, size_t len, size_t elem_size) {
      size_t vl; // 实际向量长度（VLEN 相关）
      switch (elem_size) {
          case 4: // float32 类型
              for (size_t i = 0; i < len; i += vl) {
                  vl = vsetvl_e32m1(len - i); // 设置向量长度（e32m1：32位元素，分组m1）
                  vfloat32m1_t va = vle32_v_f32m1(a + i*4, vl); // 加载向量 a
                  vfloat32m1_t vb = vle32_v_f32m1(b + i*4, vl); // 加载向量 b
                  vfloat32m1_t vc = vadd_vv_f32m1(va, vb, vl);  // 向量加法
                  vse32_v_f32m1(c + i*4, vc, vl);               // 存储结果到 c
              }
              break;
          // 可扩展 int8/int16/float16 等类型
      }
  }
  ```
- **方式2：手写 RVV 汇编**  
  适合极致性能优化，示例（float32 向量加法汇编片段）：
  ```asm
  # a0: 输出c, a1: 输入a, a2: 输入b, a3: 长度len
  loop:
      vsetvl t0, a3, e32, m1  # 设置向量长度 t0 = min(a3, VLEN/32)
      vle32.v v0, (a1)        # 加载 a 到向量寄存器 v0
      vle32.v v1, (a2)        # 加载 b 到向量寄存器 v1
      vadd.vv v2, v0, v1      # v2 = v0 + v1
      vse32.v v2, (a0)        # 存储 v2 到 c
      addi a1, a1, t0*4       # 指针偏移
      addi a2, a2, t0*4
      addi a0, a0, t0*4
      sub a3, a3, t0          # 剩余长度
      bnez a3, loop           # 循环直到 len=0
  ```

#### 步骤2：编译命令（核心！）
编译 RVV 算子的关键是指定 **RVV 架构参数**，通用编译模板：
```bash
# 交叉编译（针对 RISC-V 64 位平台）
riscv64-linux-gnu-gcc \
  -march=rv64gcv          # 启用 RV64G + RVV（rv32gcv 对应 32 位）
  -mabi=lp64d             # 应用二进制接口（64位，双精度浮点）
  -O3                     # 优化级别（推荐 O2/O3，编译器会自动向量化）
  -mvl=128                # 向量长度 VLEN（可选，如 128/256/512）
  -march=rv64gcv_zvl512b  # 显式指定 Zvl512b（最小向量长度 512bit）
  -c rvv_add.c -o rvv_add.o  # 编译为目标文件
```

#### 关键参数解释
| 参数                | 作用                                                                 |
|---------------------|----------------------------------------------------------------------|
| `-march=rv64gcv`    | 指定架构：rv64（64位）+ g（通用指令）+ c（压缩指令）+ v（RVV扩展）|
| `-mabi=lp64d`       | 64位整数 + 64位双精度浮点的ABI，适配RVV浮点运算                     |
| `-mvl=128`          | 强制向量长度为128bit（部分编译器需指定，默认自动适配硬件）|
| `-march=rv64gcv0p71`| 适配 RVV 0.7.1 版本（旧版硬件，如平头哥玄铁C908）|
| `-march=rv64gcv1p0` | 适配 RVV 1.0 版本（新版标准，推荐）|

#### 步骤3：链接为可执行文件/库
- 编译为可执行文件：
  ```bash
  riscv64-linux-gnu-gcc rvv_add.o -o rvv_add.elf
  ```
- 编译为动态库（供其他程序调用）：
  ```bash
  riscv64-linux-gnu-gcc -shared -fPIC rvv_add.o -o librvv_add.so
  ```

#### 步骤4：验证编译结果
- 检查二进制是否包含 RVV 指令：
  ```bash
  # 反汇编查看指令
  riscv64-linux-gnu-objdump -d rvv_add.elf | grep vadd
  ```
  若输出包含 `vadd.vv` 等 RVV 指令，说明编译成功。

### 四、高级配置与常见问题
#### 1. 自动向量化（无需手写 RVV 代码）
GCC 支持自动将普通循环编译为 RVV 指令，只需加 `-ftree-vectorize`：
```bash
# 普通C循环自动转为 RVV 向量指令
riscv64-linux-gnu-gcc -march=rv64gcv -O3 -ftree-vectorize normal_add.c -o normal_add.elf
```
示例普通循环（编译器会自动向量化）：
```c
void normal_add(float *c, const float *a, const float *b, int len) {
    for (int i = 0; i < len; i++) {
        c[i] = a[i] + b[i]; // GCC 会自动转为 vadd.vv 指令
    }
}
```

#### 2. 适配不同 VLEN（向量长度）
RVV 支持动态 VLEN（如 128/256/512bit），编译时无需硬编码，通过 `vsetvl` 指令动态适配（代码中已体现），只需确保 `-march` 包含 `zvl<N>b`（如 `zvl512b` 表示最小 VLEN 512bit）。

#### 3. 常见报错及解决
| 报错类型                | 原因                          | 解决方法                                  |
|-------------------------|-------------------------------|-------------------------------------------|
| `error: unknown arch`   | 编译器不支持 RVV              | 升级 GCC/Clang 到 ≥12，或重新编译工具链开启 RVV |
| `undefined reference to vadd_vv` | 未包含 `riscv_vector.h` | 代码开头加 `#include <riscv_vector.h>`    |
| `illegal instruction`   | 运行平台不支持 RVV 版本       | 编译时指定匹配的 RVV 版本（如 `-march=rv64gcv0p71`） |

### 五、实战：完整编译流程示例
```bash
# 1. 编写 RVV 算子代码（rvv_add.c）
cat > rvv_add.c << EOF
#include <riscv_vector.h>
void rvv_vector_add(float *c, const float *a, const float *b, size_t len) {
    size_t vl;
    for (size_t i = 0; i < len; i += vl) {
        vl = vsetvl_e32m1(len - i);
        vfloat32m1_t va = vle32_v_f32m1(a + i, vl);
        vfloat32m1_t vb = vle32_v_f32m1(b + i, vl);
        vfloat32m1_t vc = vadd_vv_f32m1(va, vb, vl);
        vse32_v_f32m1(c + i, vc, vl);
    }
}
EOF

# 2. 编译为目标文件
riscv64-linux-gnu-gcc -march=rv64gcv1p0 -mabi=lp64d -O3 -c rvv_add.c -o rvv_add.o

# 3. 链接为动态库
riscv64-linux-gnu-gcc -shared -fPIC rvv_add.o -o librvv_add.so

# 4. 验证 RVV 指令
riscv64-linux-gnu-objdump -d librvv_add.so | grep vadd
```

### 总结
RVV 算子编译的核心是：
1. **工具链**：使用支持 RVV 1.0 的 GCC/Clang；
2. **编译参数**：通过 `-march=rv64gcv` 启用 RVV，指定匹配的 ABI 和 VLEN；
3. **代码写法**：新手用内置函数，性能优化用汇编；
4. **验证**：反汇编检查 RVV 指令是否生成。
