> 分析日期：2026年3月04日 | 分析者：[ppdog]
> 想要在VSCode的Python项目中找出所有未被使用的函数，两种高效的实现方式（轻量插件版 + 专业静态分析版），适配不同场景。

### 方法1：VSCode插件（快速上手，无需额外配置）
推荐使用 **Pylance + Code Spell Checker** 组合（Pylance是VSCode官方Python语言服务器，内置未使用代码检测）：

#### 步骤1：确保安装Pylance插件
1. 打开VSCode → 左侧扩展栏（Ctrl+Shift+X）→ 搜索 `Pylance` → 确保已安装并启用（VSCode默认Python环境会自带）。
2. 打开设置（Ctrl+,）→ 搜索 `python.analysis.diagnosticSeverityOverrides` → 点击「在settings.json中编辑」。

#### 步骤2：配置未使用代码的检测级别
在settings.json中添加以下配置（让未使用的函数/变量高亮提示）：
```json
{
  "python.analysis.diagnosticSeverityOverrides": {
    "reportUnusedFunction": "warning",  // 未使用的函数标为警告
    "reportUnusedVariable": "warning",  // 未使用的变量标为警告
    "reportUnusedImport": "warning"     // 未使用的导入标为警告
  },
  "python.analysis.typeCheckingMode": "basic"  // 基础类型检查（足够检测未使用代码）
}
```

#### 步骤3：查看未使用的函数
保存配置后，VSCode会自动扫描项目：
- 未使用的函数会在左侧出现黄色波浪线，鼠标悬停会提示 `Function 'xxx' is not accessed`；
- 打开「问题」面板（Ctrl+Shift+M）→ 筛选「Python」→ 可批量查看所有未使用的函数/变量。

### 方法2：静态分析工具（精准度更高，支持批量导出）(亲自有效)
如果项目规模较大（上千行代码），推荐用专业工具 `vulture`（专为Python检测未使用代码设计）：

#### 步骤1：安装vulture
```bash
pip install vulture
```

#### 步骤2：扫描整个项目
在VSCode终端中进入项目根目录，执行：
```bash
# 扫描当前目录所有Python文件，输出未使用的函数/变量
vulture .

# 进阶：生成详细报告（含文件路径、行号）
vulture . --min-confidence 60 > unused_code_report.txt
```
- `--min-confidence 60`：过滤低置信度的提示（避免误判动态调用的函数）；
- `unused_code_report.txt`：报告会保存到文件，方便批量处理。

#### 步骤3：排除误判的函数
如果某些函数是被动态调用（如`getattr`、框架注册的函数），可创建 `vulture_whitelist.py` 文件，添加无需检测的函数：
```python
# vulture_whitelist.py
def my_dynamic_function():  # 被动态调用，无需检测
    pass
```
然后执行：
```bash
vulture . vulture_whitelist.py
```

### 方法3：VSCode集成vulture（一键扫描）
可以把vulture集成到VSCode的任务中，一键扫描：
1. 打开命令面板（Ctrl+Shift+P）→ 输入 `Tasks: Configure Task` → 选择「Create tasks.json from template」→ 选择「Others」。
2. 修改tasks.json为：
```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Find Unused Functions",
      "type": "shell",
      "command": "vulture . --min-confidence 60",
      "group": "none",
      "presentation": {
        "reveal": "always",
        "panel": "new"
      },
      "problemMatcher": []
    }
  ]
}
```
3. 按 `Ctrl+Shift+B` → 选择「Find Unused Functions」，即可在终端看到扫描结果。

### 关键注意事项
1. **动态调用的函数**：`vulture` 可能误判被 `eval()`、`getattr()` 或框架（如Flask/Django）注册的函数，需通过白名单排除；
2. **测试代码**：建议扫描时排除 `tests/` 目录（`vulture . --exclude tests/`）；
3. **置信度**：`vulture` 的置信度越高（如90），误判越少，但可能漏掉部分边缘场景。

### 总结
1. 轻量需求（小项目）：用**方法1（Pylance）**，无需额外安装工具，实时提示；
2. 精准需求（大项目）：用**方法2（vulture）**，支持批量导出和白名单，误判更少；
3. 便捷性优化：用**方法3**将vulture集成到VSCode，一键扫描。

这三种方式能覆盖从快速查看到大批量分析的所有场景，你可以根据项目规模选择。
