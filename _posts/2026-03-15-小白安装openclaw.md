### 🔧 什么是OpenClaw
**OpenClaw**（开源AI助手，也叫“小龙虾”），下面来教你配置和使用。

---

### 🚀 第一步：网关正确启动流程：
```powershell
# 1. 先确保网关服务已安装
openclaw gateway install --force

# 2. 启动网关（前台运行，适合调试）
openclaw gateway

# 或者作为后台服务启动
openclaw gateway start

# 3. 查看状态
openclaw gateway status
```

---

### ⚙️ 第二步：基础配置（必做）
OpenClaw 必须先配置才能正常工作，推荐用向导：
```powershell
# 完整初始化向导（推荐新手）
openclaw onboard

# 或快速配置向导
openclaw configure
```
向导会引导你：
- 选择运行模式（本地/远程）
- 绑定AI模型（如Ollama、OpenAI等）
- 设置工作目录和权限

**关键配置项：**
```powershell
# 必须设置网关模式为 local，否则无法启动
openclaw config set gateway.mode local

# 查看当前配置
openclaw config get
```

---

### 💻 第三步：三种交互方式（任选其一）
#### 1. 终端 TUI
```powershell
# 确保网关已启动后，打开终端界面
openclaw tui
```
- 输入消息按 **Enter** 发送
- 按 `!` 前缀可直接执行 shell 命令（如 `! ls`）
- 快捷键：`Ctrl+G` 切换Agent，`Ctrl+L` 切换模型

#### 2. Web 控制台（可视化，最适合新手）
```powershell
openclaw dashboard
```
浏览器会自动打开 `http://127.0.0.1:18789`，在这里：
- 可视化配置所有参数
- 直接和AI聊天
- 查看任务执行日志

#### 3. CLI 命令（适合脚本/自动化）
```powershell
# 直接发送消息给AI
openclaw message send --message "帮我写一个Python脚本"
```

    - 确认网关正在运行：`openclaw gateway status`
    - 重新连接：`openclaw tui --url ws://127.0.0.1:18789`

### 🔍 问题分析
你现在遇到的是 **网关令牌缺失（unauthorized: gateway token missing）** 错误，OpenClaw 网关启用了 token 验证，直接访问 `http://127.0.0.1:18789/chat` 会被拒绝，需要通过带 token 的仪表板 URL 访问。

---

### 🛠️ 解决步骤

#### 1. 获取带令牌的仪表板 URL
在 PowerShell 中运行以下命令，获取包含 token 的完整链接：
```powershell
openclaw dashboard
```
执行后会自动在浏览器打开类似这样的地址：
```
http://127.0.0.1:18789/?token=xxxxxxxxxxxx
```
这个 URL 里的 `token` 参数就是网关需要的验证令牌。

#### 2. 手动获取并粘贴令牌（如果自动打开失败）
```powershell
# 查看当前网关配置，找到 token
openclaw config get gateway.token
```
复制输出的 token 值，然后：
- 回到当前页面，在 **网关令牌** 输入框中粘贴 `OPENCLAW_GATEWAY_TOKEN=你复制的token`
- 或者直接在浏览器地址栏输入带 token 的 URL：
  ```
  http://127.0.0.1:18789/?token=你的token
  ```
- 点击 **连接** 按钮即可正常进入聊天界面。

#### 3. 关闭令牌验证（可选，本地调试更方便）
如果你只是在本地使用，不想每次都带 token，可以关闭网关验证：
```powershell
# 关闭网关令牌验证
openclaw config set gateway.auth.enabled false
# 重启网关生效
openclaw gateway restart
```
之后直接访问 `http://127.0.0.1:18789` 就可以免 token 连接。

### 🔍 问题原因
你现在遇到的是 **Anthropic API Key 缺失** 错误：
`Agent failed before reply: No API key found for provider "anthropic"`
OpenClaw 已经成功连接网关，但当前使用的 Claude 模型（`claude-opus-4-6`）需要有效的 Anthropic API Key 才能调用，而你的配置文件里没有提供这个密钥。

---

### 🛠️ 解决方法（两种方案任选）

#### 方案1：配置 Anthropic API Key（推荐，使用 Claude 模型）
1.  **获取 Anthropic API Key**
    前往 [Anthropic 控制台](https://console.anthropic.com/) 注册并创建 API Key。

2.  **通过 OpenClaw 命令配置**
    在 PowerShell 中运行：
    ```powershell
    # 为当前 agent 配置 Anthropic API Key
    openclaw agents auth add --provider anthropic --api-key "你的Anthropic API Key"
    ```
    或者直接编辑配置文件：
    打开 `C:\Users\admin\.openclaw\agents\main\agent\auth-profiles.json`，添加：
    ```json
    {
      "anthropic": {
        "apiKey": "你的Anthropic API Key"
      }
    }
    ```

3.  **重启网关生效**
    ```powershell
    openclaw gateway restart
    ```

---

#### 方案2：切换到本地模型（无需 API Key，离线可用）
如果你不想使用 Claude 在线模型，可以切换到本地运行的模型（如 Ollama）：

1.  **先安装并启动 Ollama**
    下载安装 [Ollama](https://ollama.com/)，然后在 PowerShell 运行：
    ```powershell
    ollama run llama3
    ```

2.  **修改 OpenClaw 配置**
    ```powershell
    # 打开配置向导
    openclaw configure
    ```
    在向导中：
    - 选择 **Model Provider** → `ollama`
    - 选择模型 → `llama3`（或你下载的其他模型）
    - 确认配置并保存

3.  **重启网关**
    ```powershell
    openclaw gateway restart
    ```
